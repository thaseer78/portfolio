# Thaseer A R — Portfolio
React 18 + Vite + TypeScript (strict) + Tailwind + Framer Motion + React Router.

    npm install
    npm run dev      # local dev
    npm run build    # type-check + production build

Edit content in `src/data/profile.ts` and `src/data/projects.ts`. Copy `.env.example` to `.env` to set a form endpoint (e.g. Formspree), a Calendly URL and a LinkedIn URL. Without an endpoint the form opens a prepared email to thaseerar789@gmail.com. Project copy is drafted from your brief: verify it, and add real `links.live` / `links.source` URLs, before publishing.
For SPA hosting on Vercel, add a rewrite of all paths to `/index.html`.
